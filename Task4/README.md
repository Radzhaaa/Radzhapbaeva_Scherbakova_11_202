#Домашка 4 — TF-IDF для терминов и лемм
По заданию нужно было для каждого скачанного документа из предыдущих заданий посчитать статистики TF-IDF.
Требовалось:
Для каждого документа подсчитать TF каждого термина (используя список токенов из предыдущего задания).
Подсчитать IDF для каждого термина по всей коллекции документов.
Подсчитать TF для каждой лемматизированной формы как отношение количества вхождений слов, принадлежащих данной лемме, к общему количеству терминов в документе.
Подсчитать IDF для каждой леммы по всей коллекции документов.
Рассчитать итоговое значение TF-IDF.
Используемые формулы:
TF(term, document) = количество вхождений термина в документ / общее количество терминов в документе
IDF(term) = log(N / df)
где
N — количество документов в коллекции
df — количество документов, содержащих термин
TF-IDF(term) = TF × IDF
Результаты сохраняются отдельно для терминов и для лемм, причём каждому документу соответствует свой файл.
Формат выходных файлов:
Для терминов:
<термин><пробел><idf><пробел><tf-idf><\n>
Для лемм:
<лемма><пробел><idf><пробел><tf-idf><\n>

Для запуска
1. Убедиться, что в папке Task1 находится распакованный архив с результатами первой домашки (папка pages).
2. Убедиться, что в папке Task3 находятся папки tokens и lemmas, полученные в предыдущем задании.
3. Открыть папку Task3 в терминале и выполнить:
python tfidf.py
Результаты будут сохранены:
в папке tfidf_terms — файлы с TF-IDF для терминов
в папке tfidf_lemmas — файлы с TF-IDF для лемм
Каждый файл соответствует одному документу из коллекции.

ссылка на данный репозиторий с кодом подсчёта TF-IDF
