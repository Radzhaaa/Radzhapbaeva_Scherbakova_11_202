# Задание 5: Векторный поиск

## Что реализовано
- WEB-интерфейс на Flask (`Task5/app.py`, маршрут `/`) с формой и выводом результатов.
- Ранжирование по TF-IDF + косинусное сходство (`Task5/vector_search.py`).
- Ограничение топ-10 результатов по каждому запросу (`top_k=10`).

## Запуск
```bash
python -m pip install -r Task5/requirements.txt
python Task5/app.py
```
Открыть в браузере: <http://localhost:1024>

## Файлы
- `Task5/app.py` — веб-приложение, HTML-шаблон, маршруты поиска и раздачи документов.
- `Task5/vector_search.py` — загрузка корпуса, построение TF-IDF, векторный поиск.
- `Task3/docs/` — коллекция документов (используется при индексации).

## Как проверить требования
1. WEB-интерфейс: открыть `/`, увидеть форму поиска и список результатов.
2. Ранжирование: результаты отсортированы по полю `score` (TF-IDF + косинус).
3. Топ-10: выдача не превышает 10 документов на запрос.
